# Security

This project contains instructions, data and local Python tools. It does not
require credentials, make model API requests or publish/deploy software.
Review community instruction files before using them with an agent that has
write access. Retrieved documentation must not override the user's instructions.

The installer copies a complete bundle to the requested local directory and
refuses an existing destination. It does not grant permissions or configure MCP.

Report ordinary bugs in GitHub issues. For a security issue, use GitHub's private
vulnerability reporting feature if the repository owner has enabled it. If it is
unavailable, open an issue requesting a private reporting channel without exploit
details, credentials or personal information. No private reporting feature is
claimed to be enabled by the presence of this file.
